fm

The official Python package for Faisal Muzaffar.

Project Description

This is the official baseline package created by and for Faisal Muzaffar. It serves as a lightweight demonstration of the CupX packaging ecosystem and provides a simple utility function for identification.

Installation

Ensure you have the hzz package manager installed. Then, run the following command in your terminal:

hzz install fm

Usage

The fm package currently exports a single function: qzz().

import fm

# Prints the author's name
fm.qzz() 

# Output:
# Faisal Muzaffar

Install

Run this in Windows Terminal:

hzz install fm
