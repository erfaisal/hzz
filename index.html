Install hzz

The official package manager for the CupX ecosystem.

Manual Download

Download the standard Windows installer. Recommended for most users.

Download Installer (.exe)
⚠️ SmartScreen Notice:

Because this is an independent open-source tool, Windows may show a blue warning screen when you open the installer.

To proceed: Click "More info", then click "Run anyway".

Terminal Quick Install

Open Windows PowerShell and paste this command to automatically download and launch the installer.

iwr -useb https://hzz.cupx.in/install/hzz-installer.exe -OutFile hzz-installer.exe; .\hzz-installer.exe
