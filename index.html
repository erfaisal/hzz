hzz

The official Windows package manager for the CupX ecosystem.

Option 1: Quick Install (Recommended)

Open Windows PowerShell and paste this command:

iwr -useb https://hzz.cupx.in/install/setup.bat -OutFile setup.bat; .\setup.bat; Remove-Item setup.bat

* Automatically downloads, installs, and cleans up the setup files.

Option 2: Manual Download

Download the ZIP file, extract it, and double-click the installer.
