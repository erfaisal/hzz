CupX Package Manager (hzz)

The official Windows package manager for the CupX ecosystem. Install, manage, and update custom python libraries seamlessly without pip.

Installation Options

Option 1: Windows Installer (.exe)

Download the standalone graphical installer. (Recommended)

Download hzz-installer.exe
⚠️ Note on Windows SmartScreen:
Because `hzz` is an independent open-source tool, Windows SmartScreen may display a blue warning when you launch the installer. To proceed with the installation: Click "More info", and then click "Run anyway".

Option 2: Terminal Install

Run this command in Windows PowerShell to automatically download and launch the installer:

Invoke-WebRequest -Uri "https://hzz.cupx.in/install/hzz-installer.exe" -OutFile "$env:TEMP\hzz-installer.exe"; Start-Process -FilePath "$env:TEMP\hzz-installer.exe"
